# 地震台网事件编目与复核台

值班组用来录台站与震相、编事件、看震级与定位残差、走复核与发布的小台子。

## 运行

```
npm install
npm start
```

默认端口 5225（`PORT` 可以覆盖），数据存在 `data/db.json`，页面在 `/`。

## 页面

- **概览**：台站数与运行中台站、事件数与各状态条数、震相/复核/发布条数、更正批次数（含更正条目数）、被更正过的事件数、最大与平均震级、满足自动发布条件的待复核事件数、超过复核容差的复核条数、重复发布过的事件数。
- **台站**：台站台账（代码、名称、区域、经纬度、仪器、状态）与各台的震相条数、人工与自动条数；台站的增改删。
- **事件**：事件清单（编号、发震时刻、经纬度、深度、震级、台站数、残差、状态、复核、发布与更正次数）；震级被更正过时会标出「更」；点行展开震相、自动发布判定、复核历史、发布记录与**对外口径时间线**、更正记录，可登记复核、发布与更正。
- **震相**：震相清单（台站、相位、到时、振幅、走时残差、拾取方式与质量），支持单条新增、批量导入与删除。
- **复核与发布**：复核记录、发布记录与**更正台账**。更正批次一行可展开查看受影响事件清单与各事件改前→改后；「批量登记更正」可一次把多个事件挂到同一批次（同一时刻、更正人、依据）。

## 口径（这一版按下列规则实现，页面上的说明与数字都要与本段一致）

1. **单台震级**：`lg(A) + 1.11 × lg(R) + 0.00189 × R − 2.09`，A 是振幅（微米），R 是震中距（公里）；**事件震级取各台站单台震级的中位数**，并给出参与台站数。
2. **震中距**：按球面距离算（两点经纬度，地球半径 6371 公里）。
3. **走时残差**：事件的残差是各条震相残差的均方根；**没有任何震相记录的事件不能自动发布**，只能走人工。
4. **自动发布条件**：震级不低于 `autoPublishMagnitude`（默认 4.0）、参与台站不少于 `minStationCount`（默认 4 个）、走时残差不大于 `rmsLimitSec`（默认 3.0 秒）、震源深度不超过 `shallowDepthLimitKm`（默认 70 公里，只自动发布浅源事件）。四条同时满足才自动发布。
5. **复核容差**：震级改动**超过** `reviewToleranceMagnitude`（默认 0.3）才需要上级确认；正好等于容差不算超。
6. **震相导入**：按「台站 + 相位 + 到时」去重，已经有的重复记录要跳过并在结果里报出跳过条数。
7. **台站代码**：大小写与首尾空格不敏感，同一个台站只能算一个台站。
8. **事件清单排序**：按震级从大到小，震级相同时按发震时刻从新到旧。
9. **最新复核**：一条事件的「最新复核」按复核时刻取，不是按录入先后。
10. **同一事件只能有一条有效发布**；重复发布要拦下并提示已经发布过。
11. **发布之后的修订一律走「更正」，不能直接改事件或借复核抹掉**：已发布事件的震级、经纬度、深度、发震时刻、区域、震级类型通过 PATCH 直接改会被拦（`EVENT_PUBLISHED_LOCKED`），复核接口也不再接受这些字段的改动；状态、备注等非口径字段仍可正常修改。
12. **更正登记内容**：更正时刻、更正人、更正依据、勾选的更正项、每项的改前值与改后值（另可填备注）；只有「已发布」的事件能登记更正，勾选项必须与当前口径有差异，否则整次登记拒绝。
13. **当前对外口径立即更新、历史不许抹**：更正落库后事件上的当前震级/位置立刻是最新值（震级取最近一次更正值，没更正过取台站中位数）；每一条发布记录在发布当时完整快照震级与位置，之后不再改动。事件详情的「对外口径时间线」把发布与更正按时刻排在一起，能看出第一次发的是多少、第几次更正改成了多少。
14. **批量更正**：一次更正影响多个事件（如同一批台站定标后统一调整）时，共用一个批次号、一个更正时刻/更正人/依据，下面挂各受影响事件及各自的改前→改后；整批先统一校验，任一行不合法则整批不入库。事件上展示「发布过几次、更正过几次」，概览展示更正批次数、更正条目数与被更正过的事件数。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/health、/api/summary、/api/settings | 健康检查、概览、全局设置（PATCH 可改） |
| GET / POST | /api/stations | 台站清单 / 新增 |
| GET / PATCH / DELETE | /api/stations/:id | 台站详情（含该台震相）/ 修改 / 删除 |
| GET / POST | /api/events | 事件清单（支持 status、minMagnitude、regionName、from、to）/ 新增 |
| GET / PATCH / DELETE | /api/events/:id | 事件详情（含震相、复核、发布、更正条目与对外口径时间线）/ 修改（已发布事件的口径字段会被拦）/ 删除（已发布要带 force 与理由） |
| POST | /api/events/:id/reviews | 登记复核（可改震级与深度；已发布事件改口径会被拦，要走更正） |
| POST | /api/events/:id/publish | 发布（`auto: true` 表示走自动发布，不满足条件会被拦下）；发布当时完整快照震级与位置 |
| POST | /api/events/:id/corrections | 单个事件登记更正，body `{at?, corrector, reason, fields:[...], after:{...}, remark?}` |
| GET | /api/events/:id/auto-check | 单独看这个事件的自动发布判定 |
| GET | /api/reviews、/api/publishes | 复核台账（支持 eventId、reviewer、overTolerance）/ 发布台账（支持 eventId、type） |
| POST / GET | /api/corrections | 批量登记更正（body `{at?, corrector, reason, items:[{eventId, fields, after, remark?}], remark?}`）/ 更正批次清单（支持 eventId、corrector），点一批可看各事件改前改后 |
| GET | /api/corrections/entries | 摊平的「事件 × 更正条目」（支持 eventId） |
| GET / POST | /api/arrivals | 震相清单（支持 eventId、stationId、phaseType、pickType、from、to）/ 单条新增 |
| POST | /api/arrivals/import | 批量导入，body `{eventId, rows:[...], picker}` |
| DELETE | /api/arrivals/:id | 删除一条震相 |

出错的返回统一是 `{"error":{"code":"...","message":"...","details":{...}}}`，`details` 里会点名是哪个字段没过。
